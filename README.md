# Currency Converter

A small currency converter built with plain HTML, CSS, and JavaScript while learning browser APIs and asynchronous JavaScript.

**Live site:** [radekkuc.github.io/CurrencyConverter](https://radekkuc.github.io/CurrencyConverter/)

## Features

- Convert amounts in either direction using exchange rates from the Frankfurter API.
- Choose from currencies loaded from the API and swap the selected pair.
- Update amounts locally while typing, without requesting a new rate for every keystroke.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

The static site is deployed to GitHub Pages by a GitHub Actions workflow when changes are pushed to `main`.
